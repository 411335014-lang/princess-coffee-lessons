# 公主的女僕咖啡教室

解壓縮後直接開啟 `index.html`，就能從目錄進入講義。本站使用靜態 HTML 和共用 CSS。

## 維護講義

從 [AGENTS.md](AGENTS.md) 開始。依照其中的規則複製現有講義、更新首頁入口，再檢查手機版、測驗和返回連結。

## 發布到 GitHub Pages

1. 建立 GitHub 儲存庫，將解壓縮後的專案內容上傳至 `main`。確認儲存庫根目錄就能看到 `index.html`。
2. 在儲存庫開啟 **Settings → Pages**，選 **Deploy from a branch**，再選 **main → /(root)** 並儲存。
3. 發布完成後，在 Pages 設定按 **Visit site**。之後將講義更新推送到同一分支，Pages 就會重新發布。

[GitHub Pages 官方設定說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
